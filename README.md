# 工程材料A · 刷题台

基于课程全套课件（14份PPT + 2份PDF）与 2021/2022 两套期中真题整理的智能刷题工具。

## 功能
- 227 道题 · 12 个章节（绪论/钢分类编号/合金化/构件钢/机器零件用钢/工具钢/不锈钢/耐热钢/固态相变/热处理/有色金属/期中真题）
- 章节刷题、随机刷题、错题本、收藏
- 89 张速记卡 · 12 章思维导图 · 知识提纲
- 学习统计（各章正确率）
- 手机端打开即进入随机刷题，底部 Tab 导航

## 在线访问
https://sanabesito.github.io/materials-shuati/

## 技术
单文件自包含 HTML（零外部依赖、离线可用），数据内置，localStorage 记录学习进度。
